Gerbers files to produce TK95 keyboard boards to substitute membranes. you can use original acetate and upper membrane to make contact for the keys, since at least key contact points are working. Or you can coat that points with some conduct ink or even stick some conduct material in that or use MX switches for a complete mechanical keyboard.
